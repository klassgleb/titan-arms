# Titan Arms — лендинг

Одностраничный адаптивный сайт на React, Vite, Tailwind CSS и Framer Motion. Интерфейс на русском языке; исходные скриншоты профиля сохранены в `public/assets`.

## Запуск

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Контакты, карточки и демо-оформление

Контакты, тарифы, галерея и данные тренеров собраны в `src/data.js`. Фотографии и карточки Андрея Гвоздева, Христофора Пескелиди и Кристины Иващенко предоставлены залом и размещены в `public/assets`.

Оформление абонемента работает в демо-режиме: выберите тариф, заполните ФИО и телефон, затем Kaspi или Halyk. Подтверждённая демо-заявка сохраняется в `localStorage` под ключом `titanArmsDemoOrders`. Интеграции с банками нет, списаний средств нет. После подтверждения отображаются данные демо-заказа и инструкция по активации абонемента на стойке администрации.

Формы персональной тренировки открывают WhatsApp с подготовленным сообщением. Instagram ведёт на `@titan_arms_gym`. Рабочие часы будней и субботы уточняются напрямую у зала; воскресенье — выходной. Галерея использует изображения Unsplash.
